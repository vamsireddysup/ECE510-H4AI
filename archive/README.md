# Archive

I keep old coursework, experiments, and local reference material here so the
repository root stays focused on the active accelerator.

## Contents

- `coursework/project/`: my original M1-M4 project files and reports
- `coursework/codefest/`: weekly course exercises
- `experiments/smoke_test/`: the original Verilator environment check
- `reference/`: ignored local reference material
- `local/`: ignored local tools and environments

The tracked coursework files are historical records. I do not use them as the
source for new RTL changes. The active design is under [`../rtl/`](../rtl/README.md).
